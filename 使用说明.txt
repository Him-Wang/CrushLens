CrushLens 心动镜 v1.2 · 使用说明
================================

一、启动
1. 把 CrushLens.exe 放在一个你有写入权限的文件夹里（例如 D:\CrushLens 或 U 盘）。
2. 双击即可，无需安装，不需要管理员权限。
3. 需要 Windows 10/11 和 .NET Framework 4.8（系统通常已自带）。

二、接入自己的 API Key
1. 点左下角「设置」。
2. 选择服务商预设，或选「自定义 / 本机接口」。
3. 填 Base URL、模型 ID、API Key。DeepSeek 文字模型示例：
   Base URL: https://api.deepseek.com/v1
   模型 ID:  deepseek-chat
4. 点「检测连接」，成功后再保存。
5. 如果平台支持模型列表，可点「获取模型列表」后选择。
6. 本工具不附带任何 Key；费用由你的 API 账户承担。

注意：图片 / 表情包分析需要模型支持视觉输入。
普通文字模型（如 deepseek-chat）收到图片会报错，请换用支持
OpenAI image_url 内容格式的视觉模型。

三、分析聊天和图片
1. 在分析台顶部选择「Crush 心动」或「情侣关系」。
2. 复制聊天记录，或把 .txt/.json 文件拖进输入框。
3. 可选：点输入框下方的「＋」添加聊天截图 / 表情包，最多 6 张。
   支持 PNG/JPG/JPEG/BMP/GIF；GIF 只读第一帧。
   图片会先在本机压缩到最长边 1400px，再随节选发送给 API。
4. 选择「我是」和对方（Crush 显示「对方是」，情侣显示「伴侣是」）及关系阶段；
   情侣关系可选稳定恋爱、磨合期、异地恋等。
5. 分析范围可选最近 80/120/200 条；本地统计始终覆盖全部所选消息。
6. 点「开始分析」。AI 会收到本次选中的文字节选和已选图片。
7. 如果只添加图片、不粘贴文字，也可以做纯图片分析；
   此时看板没有文字统计，报告主要依据图片。
8. 报告生成后会自动保存在本机，可在「聊天档案」再次打开，或导出 HTML。

四、支持格式
- 微信三行：昵称 / 年月日时间 / 正文
- 「昵称: 2026-09-20 21:14 内容」
- QQ：「昵称: 09-17 19:26:53」下一行正文
- WhatsApp 导出的 [日期, 时间] 昵称: 内容
- JSON 数组，或 { messages: [...] }，字段见 README
- 图片：PNG / JPG / JPEG / BMP / GIF（GIF 第一帧）

五、分数怎么算
Crush 模式的六个维度：主动延续、回应投入、关心体贴、
自我开放、亲密表达、实际行动。

情侣模式的六个维度：安全感、双向投入、沟通修复、
边界尊重、亲密连接、共同未来。

程序在本地按各自权重合成最终分数，模型原始分只作参考。
因此不同对话不会因为模型偷懒而都显示 72。
Crush 分数是互动好感信号，不是对方喜欢你的概率；
情侣关系分是沟通与连接信号，不是心理诊断或去留建议。

六、数据在哪里
所有数据都在 exe 旁边的 CrushLens_Data 文件夹：
  settings.json     设置，Key 使用 Windows DPAPI 加密
  sessions\*.json   聊天与分析档案
  media\            压缩后的图片 / 表情包附件
  exports\          你导出的 HTML
  app.log           错误日志
程序自身不创建注册表项、AppData 文件、服务或计划任务；
DPAPI 的系统主密钥由 Windows 管理，不包含聊天内容。
删除 CrushLens_Data 即清空本工具全部本地数据。
换电脑/换 Windows 用户后，需要重新填写 API Key（DPAPI 绑定当前用户）。
迁移时请同时复制 sessions 和 media 两个目录。

七、边界
- 分数是聊天中的互动好感信号，不是对方喜欢你的概率。
- 不读心、不诊断、不保证关系结果。
- 图片可能包含头像、姓名、住址等隐私；发送给视觉 API 前请自己确认。
- 图片可能模糊或被误读；看不清时报告应写“不确定”，不要当成事实。
- 明确拒绝就是拒绝；请尊重边界，不要用报告去操控或试探对方。
- AI 会出错；请以真实相处和直接沟通为准。
- 未签名 exe 可能触发 SmartScreen：可核对 SHA256，或从源码自行编译。

八、卸载
退出程序，删除 CrushLens.exe 和 CrushLens_Data 即可。
