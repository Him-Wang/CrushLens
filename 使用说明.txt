CrushLens 心动镜 v1.0 · 使用说明
================================

一、启动
1. 把 CrushLens.exe 放在一个你有写入权限的文件夹里（例如 D:\CrushLens 或 U 盘）。
2. 双击即可，无需安装，不需要管理员权限。
3. 需要 Windows 10/11 和 .NET Framework 4.8（系统通常已自带）。

二、接入自己的 API Key
1. 点左下角「设置」。
2. 选择服务商预设，或选「自定义 / 本机接口」。
3. 填 Base URL、模型 ID、API Key。DeepSeek 示例：
   Base URL: https://api.deepseek.com/v1
   模型 ID:  deepseek-chat
4. 点「检测连接」，成功后再保存。
5. 如果平台支持模型列表，可点「获取模型列表」后选择。
6. 本工具不附带任何 Key；费用由你的 API 账户承担。

三、分析聊天
1. 复制聊天记录，或把 .txt/.json 文件拖进输入框。
2. 选择「我是」「对方是」和关系阶段。
3. 分析范围可选最近 80/120/200 条；本地统计始终覆盖全部所选消息。
4. 点「开始分析」。AI 只会收到本次选中的节选。
5. 聊天里的情绪/意图标签、右侧报告、看板都可以分别查看。
6. 报告生成后会自动保存在本机，可在「聊天档案」再次打开，或导出 HTML。

四、支持格式
- 微信三行：昵称 / 年月日时间 / 正文
- 「昵称: 2026-09-20 21:14 内容」
- QQ：「昵称: 09-17 19:26:53」下一行正文
- WhatsApp 导出的 [日期, 时间] 昵称: 内容
- JSON 数组，或 { messages: [...] }，字段见 README

五、数据在哪里
所有数据都在 exe 旁边的 CrushLens_Data 文件夹：
  settings.json     设置，Key 使用 Windows DPAPI 加密
  sessions\*.json   聊天与分析档案
  exports\          你导出的 HTML
  app.log           错误日志
程序自身不创建注册表项、AppData 文件、服务或计划任务；
DPAPI 的系统主密钥由 Windows 管理，不包含聊天内容。
删除 CrushLens_Data 即清空本工具全部本地数据。
换电脑/换 Windows 用户后，需要重新填写 API Key（DPAPI 绑定当前用户）。

六、边界
- 分数是聊天中的互动好感信号，不是对方喜欢你的概率。
- 不读心、不诊断、不保证关系结果。
- 明确拒绝就是拒绝；请尊重边界，不要用报告去操控或试探对方。
- AI 会出错；请以真实相处和直接沟通为准。
- 未签名 exe 可能触发 SmartScreen：可核对 SHA256，或从源码自行编译。

七、卸载
退出程序，删除 CrushLens.exe 和 CrushLens_Data 即可。
