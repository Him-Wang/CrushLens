# legacy/ —— 旧版网页版（v1.3）

这个目录里只有一份文件：`index.html`，v1.3 的单文件网页版（三模式 / 五主题 / 自己填 API Key）。

- 它**不再**是线上入口。线上现在是仓库 `web/` 目录里那套（由 `.github/workflows/pages.yml` 发布到站点根）。
- 它仍然可以**双击直接打开**：不依赖同目录的 `assets/`、`src/`，所有样式与脚本都在文件里。
- 想还原到旧版线上入口时，把它复制回仓库根并改名 `index.html` 即可（同时要把 Pages 的发布方式切回分支发布）。

对比一下两套东西：

| | legacy（这份） | web/（现在线上这份） |
| --- | --- | --- |
| 分析 | 调你自己填的 API Key，由模型给分 | 纯本地引擎算分，不需要 Key |
| 数据 | localStorage + 档案 | IndexedDB（账号 / 追踪对象 / 批次 / 报告 / 审计） |
| 入口 | 单文件 | 用户端 `index.html` + 开发端 `admin.html` |
| 聊天导入 | 粘贴 / 截图 | 粘贴 / 截图 OCR / 直连本机助手 |
