# 心动镜微信记录读取器

Windows 独立工具：从本机微信电脑版**只读**提取聊天记录，导出为心动镜（`engine.js` 的 `parseChat`）可直接解析的文本文件。

导出文件格式：

```text
2026-01-01 12:00:00 昵称：消息内容
```

## 文件清单

| 文件 | 用途 |
| --- | --- |
| `心动镜微信记录读取器.ps1` | 主程序：版本检测、只读内存扫描、密钥校验、解密、导出、自检 |
| `启动微信读取器.bat` | 双击启动器（自动切换到 UTF-8 代码页并绕过执行策略） |
| `README.md` | 本文档 |

发布包 `心动镜微信记录读取器-v1.0.0.zip` 内仅含上述 3 个文件。

## 使用方法

1. 在电脑上启动并登录微信电脑版，确保至少产生过一条聊天记录。
2. 双击 `启动微信读取器.bat`（或在 PowerShell 中运行主脚本）。
3. 依次选择会话、导出范围（全部 / 最近 90 天）。
4. 导出文件生成在 `%USERPROFILE%\Documents\心动镜导入\`，文件名格式为 `名字-微信-YYYYMMDD.txt`。将该文件导入心动镜即可。

离线自检（不需要微信进程、不联网）：

```powershell
powershell -File "心动镜微信记录读取器.ps1" -SelfTest
```

全部检查通过时输出 `selftest=ok` 并以退出码 0 结束；任何一项失败输出 `selftest=failed` 并以退出码 1 结束。自检使用内存中的合成数据库（伪造 `SQLite format 3\0` 头部、用已知密钥加密第一页），验证正确密钥通过、错误密钥被拒绝，并覆盖版本解析、十六进制候选识别和导出文件名格式。

## 运行条件

- Windows 7 / 8 / 10 / 11，PowerShell 5.1（系统自带）。
- 微信电脑版 3.x 或 4.x，已登录并产生聊天记录。
- 不需要管理员权限；不需要安装任何第三方运行库。

## 安全与隐私说明

- **只读内存**：仅调用 `OpenProcess(PROCESS_VM_READ | PROCESS_QUERY_INFORMATION)` 与 `ReadProcessMemory`，不写入进程内存、不注入代码、不创建远程线程。
- **不联网、不开端口**：没有网络访问，没有监听套接字，没有后台驻留进程。
- **明文不出导出目录**：解密后的数据库临时文件只写入 `%USERPROFILE%\Documents\心动镜导入\`，且在程序退出时（含异常路径）删除。内存中生成的合成数据库不落盘。
- **零付费服务**：不调用任何在线接口。
- 导出的聊天记录包含个人隐私，请自行保管，不要随意转发。

## 风险提示

- 读取其他进程内存可能被安全软件拦截；本工具不会关闭或绕过安全软件，请自行评估并决定是否允许。
- 微信版本更新可能改变内存布局或 SQLCipher 参数，导致无法定位密钥或解密失败。此时需要更新工具，而不是反复重试。
- 本工具仅用于导出**本人有权访问**的聊天数据。请遵守当地法律法规与平台服务条款，不要用于侵犯他人隐私。

## 故障排查

| 现象 | 原因与处理 |
| --- | --- |
| `未检测到微信进程` | 先启动并登录微信电脑版；注意 4.x 进程名可能是 `Weixin`，工具已兼容两种名称。 |
| `无法识别微信版本` | 版本过旧或过新；工具仅支持主版本号 3 与 4。 |
| `读取微信进程内存被拒绝` / `内存读取全部失败` | 安全软件的内存防护拦截，或进程权限不足。请以登录微信的同一用户运行，并临时允许本工具的内存读取；必要时完全退出微信后重试。 |
| `未找到微信数据库文件` | 检查 `文档\WeChat Files`（3.x）与 `文档\xwechat_files`（4.x）路径是否被修改过。 |
| `数据库文件被占用或无法读取` | 数据库被微信锁定。请完全退出微信（包括托盘图标）后重试。 |
| `未在内存中定位到数据库密钥候选` | 微信刚启动、内存中尚无密钥，或版本布局变化。重启微信并产生新聊天记录后重试。 |
| `数据库解密失败` | 密钥候选全部未通过头部校验，通常是版本或 SQLCipher 参数不匹配。请确认微信版本，并检查是否需要更新工具。 |
| `未解析到任何联系人会话` / `未读取到该会话的消息` | 数据库表结构与内置解析规则不匹配（详见下方限制）。 |

## 已知限制

- 内置自研的**最小 SQLite 读取器**，不依赖 `System.Data.SQLite.dll`，因此不需要额外安装运行库；但它只实现了解析所需的表 B 树、记录格式与溢出页，**不支持**索引、WAL 文件中的未落盘事务、复杂表达式或任意 SQL 查询。若微信刚好把最新消息留在 WAL 中，可能需要完全退出微信使数据落盘后再运行。
- 已适配常见的 3.x `Session` / `MSG` 表，以及 4.x 的部分 `Msg_*` / `message_*` 表与字段命名；微信后续改表结构时，需要在脚本的表/字段识别规则中补充映射。
- SQLCipher 参数按版本写死：3.x 使用 `kdf_iter=64000`、HMAC-SHA1；4.x 使用 `kdf_iter=256000`、HMAC-SHA512、页大小 4096。校验时同时尝试两种 HMAC 密钥派生方式（单步 PBKDF2 与真实 SQLCipher 的两步 fast-kdf）。若个别版本使用其它参数，需要调整脚本中的 `Get-CipherProfile`。
- 内存扫描对二进制 32 字节密钥采用“高熵 + 邻近数据库特征字符串”的启发式排序，并限制校验候选数量（1500 个）；极端情况下可能需要多试几次，或依赖十六进制字符串候选（3.x 常见）。
- 群聊默认隐藏，可在会话菜单按 `G` 切换显示。
- `engine.js` 的解析规则对昵称长度有 26 字符限制；超长昵称可能无法被正确识别，导出文本本身不受影响。

## 退出码

- `0`：成功（含自检通过）。
- `1`：失败（含自检失败、环境不满足、解密失败等）。
