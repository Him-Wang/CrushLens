# CrushLens Web —— 心动镜·情感追踪（云端重制版）

对原版 [CrushLens](https://github.com/Him-Wang/CrushLens)（C# WinForms 桌面程序）的全面重制：
迁移为**纯前端 Web 应用**，零后端、零依赖、双击即用，并在此基础上新增了一整套
情感追踪 / 复盘预测 / 多平台导入 / 权限监管能力。

## ✨ 功能总览

### 用户端（index.html）
- **情感浓度动态追踪**：逐日 0–100 打分曲线、7 日均线、转折点自动标记，支持 14/30/90 天切换
- **复盘与预测**：自动生成复盘卡片（峰值日/低谷日/升温降温/风险信号），未来 7 天预测含置信区间
- **五维分析**：主动度、回应度、亲密度、情绪波动、节奏同步（雷达图）
- **多平台导入**：微信（电脑版导出 & 手机合并转发）、QQ、钉钉、WhatsApp、通用 JSON，粘贴或拖文件均可
- **截图识别导入**：聊天截图（绿/白气泡）本地 OCR 自动识别"谁说的、说了什么、哪天"，图片不上传
- **直连本机**：配合 `assistant/` 下的零依赖连接助手，自动扫描本机聊天记录文件、按人名聚合、一键导入、20 秒自动同步；支持投递箱（文档\心动镜导入）
- **追踪对象分组**：按聊天对象保存与增量导入（指纹去重，重复粘贴自动跳过）
- **实时监测**：增量粘贴 + 多标签页同步 + 定时重算
- **使用记录**：导入流水、报告快照，随时回看

### 开发端监管台（admin.html）
- 总开发者唯一最高权限（首次认领制，不可撤销）
- 监管所有用户的使用次数、导入来源平台、时段分布
- 聊天内容调阅仅限总开发者，被分享权限的开发者只能申请限时授权（到期自动失效）
- 全量审计日志

## 🚀 快速开始

无需构建、无需安装：

```bash
# 任意静态服务器即可
python -m http.server 8080
# 打开 http://localhost:8080
```

- 用户端：`index.html`
- 开发端：`admin.html`（登录后点"成为总开发者"，第一个认领的账号即唯一总开发者）

### 直连本机（Windows）

打开网页 →「直连本机」→ 下载 `assistant/心动镜连接助手.zip` → 解压 → 双击 `启动助手.bat`。
浏览器弹出「允许访问本地网络」时点允许。

## 📁 目录结构

```
├── index.html          # 用户端
├── admin.html          # 开发端监管台
├── assets/
│   ├── engine.js       # 解析器 + 情感浓度/趋势/预测引擎（纯本地计算）
│   ├── store.js        # IndexedDB 存储层 + 账号/权限/审计
│   ├── ocr.js          # 截图识别（tesseract.js 自托管）
│   ├── ui.js           # 图表/图标/弹窗组件
│   ├── app.js          # 用户端逻辑
│   ├── admin.js        # 监管台逻辑
│   ├── vendor/         # tesseract.js 引擎与 wasm 内核（自托管，不依赖 CDN）
│   └── tessdata/       # 中文 OCR 语言包
└── assistant/          # Windows 连接助手（零依赖 PowerShell）
```

## 🔒 隐私说明

- 所有分析在浏览器本地完成，聊天记录默认不上传任何服务器
- OCR 识别完全本地执行（引擎与语言包随站点自托管）
- 连接助手只监听 `127.0.0.1`，仅响应本机请求

## 与原版的关系

原版为 C# WinForms 单机程序；本仓库版本为全新 Web 实现，
保留了"本地分析、自己掌控数据"的初衷，补齐了移动端可用性、
多人权限监管与自动化导入能力。
